## 🎓 교육 기본방향

### 5가지 교육 가치
1. **🌱 자율** - 스스로 배우는 아이
2. **🌿 생명** - 자연을 사랑하는 아이
3. **👥 관계** - 함께 자라는 아이
4. **📖 이야기** - 이야기로 성장하는 아이
5. **❤️ 인성/사랑** - 사랑을 실천하는 아이

## ✨ 강릉유치원만의 특별한 배움

### 01. 스스로 배우는 힘, 몬테소리
스스로 선택하고 반복하며 몸과 마음의 경험을 통해 자립심과 배움의 힘을 키웁니다.

### 02. 이야기로 세상을 만나는 그림책
매일 좋은 그림책을 만나 듣고, 상상하고, 질문하고 표현하여 생각의 세계를 넓혀갑니다.

### 03. 마음의 뿌리를 세우는 기독교 인성교육
믿음, 소망, 사랑 안에서 감사하는 배려를 배우고 생활 속에서 실천합니다.
